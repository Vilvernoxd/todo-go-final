# TODO-планировщик на Go

Это мой итоговый проект по Go: небольшой веб-сервер с TODO-листом (планировщиком задач).
Сервер раздаёт фронтенд из папки web и работает с задачами через API.
Задачи хранятся в SQLite базе scheduler.db.

## Что реализовано
- добавление задачи;
- список задач (ближайшие, отсортированы по дате);
- получение задачи по id;
- редактирование задачи;
- удаление задачи;
- отметить задачу выполненной (разовая удаляется, повторяющаяся переносится на следующую дату).

## Как запустить проект
Перейти в корень проекта и выполнить команду:
go run .

После запуска открыть в браузере:
http://localhost:7540/

## Как запустить тесты
Сервер должен быть запущен в отдельном терминале:
go run .

В другом терминале выполнить:
go test ./tests

Файл tests/settings.go не меняла, используются значения по умолчанию.
